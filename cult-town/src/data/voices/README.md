# 대사 작성 지침 (24장 B)

이 폴더 파일은 주민 열 명씩 대사를 담는다. 먼저 `cult-town/CLAUDE.md` 의 0장(원칙), 14장(문장 규칙), 24장 B(대사 형식)를 읽는다.

## 꼭 지킬 것
- 큰따옴표로 감싼 한 줄짜리 말. 지문은 대사 묶음에 넣지 않는다 (사연 text 의 지문만 예외).
- 처음 보는 사람에게 속마음을 털어놓지 않는다. `hit` 은 호감 40 미만: "아 뭐… 그런 것도 있죠" 정도로 얼버무리거나 딴소리. 진짜 속얘기는 `hitClose` 에서도 조금씩.
- 숫자는 그 사람이 진짜 신경 쓰는 것 하나만 가끔. 한 주민 대사 중 숫자(0-9)가 든 줄이 30%를 넘으면 안 된다. 보통은 10% 안쪽.
- 말줄임표(…)로 시작하는 줄은 한 주민당 20% 이하. 말줄임표 자체도 드물게.
- 대부분 평범하게 끝난다. 웃긴 마무리·반전 한 줄 금지. 줄표(—) 금지. "A일 수도 B일 수도" 금지. 세상·운명·빛·영혼 같은 추상어 쓰지 않는다.
- 불완전한 말: 말이 끊기고, 같은 말 반복, 주어 생략, 엉뚱한 대답, 되묻기. 어르신은 존댓말에 반말이 섞인다. 20대는 줄임말·유행어(과하지 않게, "ㅋㅋ"는 가끔). 사투리: 남궁철 경상도 · 배영숙 전라도 · 마금례 충청도 (진하지 않고 자연스럽게).
- 모두가 성실히 반응하지 않는다: 폰 보면서 건성으로 "네네", 바쁘다고 끊기, 자기 얘기만 하는 사람, 못 들은 척.
- 같은 사람 안에서 같은 줄 중복 금지. 다른 사람과도 같은 줄 금지.
- 주민끼리 아는 사이(관계)는 residents.js RELATIONS / residents-bongcheon.js RELATIONS_B 를 보고 자연스럽게 언급해도 된다.
- 교주의 말은 쓰지 않는다. 설득 화법·포섭 대본 금지. 주민의 반응만.
- 기성 종교(교회·절·무당) 이야기는 진지하게. 사이비 쪽만 풍자.
- 교주와 주민 사이 연애·성적 뉘앙스 금지.
- 토큰: `{성소}` (성소를 부를 때. "302호" 대신), `{호칭}` (member 인사에서 교주 부르는 말), `{교단}`, `{예배}`, `{교주}`.
- 주민 이름·나이·직업·성격·종교·고민(needs)·bio 를 반영해 서로 다른 사람처럼.

## 형식
```js
export const VOICES_N = {
  <주민 id>: {
    first: '"첫 만남 인사 한 줄"',
    call: '선생님',
    greet: [5줄], close: [4], member: [4], smalltalk: [5],
    hit: [4], hitClose: [4], partial: [4], miss: [4],
    preachGood: [4], preachBad: [4], inviteYes: [4], inviteNo: [4],
    refuse: [4], again: [4],
    ctx: { morning: [1~2], evening: [..], rain: [..], cold: [..], hot: [..], monday: [..], friday: [..], weekend: [..],
           semester: [..], cherry: [..], holiday: [..], monsoon: [..], chuseok: [..], yearend: [..], afterWorship: [..], again: [..] },
  },
};
// 사연 (기존 사연을 새로 쓴다). 주민마다 3개. favor 의 type·item·to·place 값은 그대로 둔다 (게임 균형).
export const STORIES_N = {
  <주민 id>: [ { title, text: ['짧은 지문 1줄 (형태를 바꿔 가며: "OOO가 ~한다." 틀만 반복 금지)', '"대사 1~2줄"'], favor: { type, item|to|place, ask, done, relay?, note? } }, ... ],
};
```
- ctx 는 키 16개 중 10개 이상 채운다. 계절 행사 키: semester(3월 개강) · cherry(4월 도림천 벚꽃) · holiday(5월 연휴·부처님오신날) · monsoon(6~7월 장마) · chuseok(9월 추석) · yearend(12월 연말).
- afterWorship: 어제 저녁 {성소}에서 예배가 있었던 날. 신도가 아니어도 소리·불빛·계단 사람들 같은 걸 봤다는 식.
- 사연: 1단계(호감 25)는 가벼운 생활 이야기, 2단계(45)·3단계(65)로 갈수록 조금 더 속얘기. 처음부터 비밀 고백 금지. 숫자는 사연 하나에 많아야 하나.
