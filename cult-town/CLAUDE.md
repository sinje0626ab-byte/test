# CLAUDE.md — 신림동 교주 (가제, 이름 미정)

> 게임 이름은 아직 정하지 않았다. 정해지면 `src/config.js`의 `GAME.title`과 `index.html`의 `<title>`만 바꾼다.
> 이 문서가 설계 기준이다. 설계가 바뀌면 코드보다 이 문서를 먼저 고친다.
> `../faith-game/`(지구본 전략 게임)은 건드리지 않는다. 참고만 한다.

## 0. 원칙 (어기지 않는다)
- 실존 사이비 단체의 이름, 교주, 사건, 교리 용어를 쓰지 않는다. 교단 유형은 여러 사례에 공통된 **패턴** 수준으로만 만든다.
- 성범죄, 집단 자살·사망 같은 실존 피해를 연상시키는 콘텐츠는 넣지 않는다.
- 풍자 대상은 **플레이어의 사이비뿐**이다. 정통 교회 목사, 절 스님, 동네 무당 같은 기성 종교 인물은 우스개가 아니라 사이비를 경계하고 막는 **진지한 상대**로 그린다.
- 세 계열(기독교풍·불교풍·민간신앙풍)은 같은 규칙과 같은 무게로 다룬다. 수치·대사량·개입 강도를 계열마다 똑같이 맞춘다.
- 포교 대화는 호감도·고민 카드·선택지 같은 **게임식 장치**로만 표현한다. 현실에서 따라 할 수 있는 포섭 대본·화법·단계별 수법은 쓰지 않는다. 선택지 문구는 "고민 들어주기", "성소 얘기 꺼내기"처럼 행동의 이름만 쓰고, 실제 설득 문장은 쓰지 않는다.
- 동네 이름·역·큰길은 실제 이름(신림동, 신림역, 남부순환로, 신림로, 도림천)을 쓴다. 가게·교회·절·건물·인물 이름은 전부 지어낸다.
- 어두운 선택에는 나중에 돌아오는 대가가 있다 (그림자 장부 `shadow`).
- 교주와 신도 사이의 연애·성적 관계, 외도는 넣지 않는다. 교주가 권력으로 신도를 상대하는 구조는 실존 피해 패턴이다.
- 연애·바람·부부 싸움 같은 드라마는 **주민끼리만** 일어난다 (24장 D-4). 묘사는 소문·말풍선 수준. 성적인 묘사 금지.

## 1. 개요
- 서울 신림동에서 평범한 사람이 사이비 교주가 되는 블랙코미디 게임.
- RPG(동네를 걸어 다니며 직접 포교) + 경영(성소 운영) + 심즈(주민 30명이 각자 일과·욕구·관계를 가지고 산다).
- 시점: 위에서 비스듬히 내려다보는 16px 도트 (RPG Urban Pack 화풍).
- 루프: **낮** 동네 RPG(포교) → **밤** 성소 경영(예배, 소품, 신도 돌보기, 잠) → **일요일 밤** 주보(한 주 결산).

## 2. 기술·배포
- Vite + Phaser 3 + 바닐라 JS (ES 모듈).
- **UI 오버레이는 전부 DOM** (대화창, 프로필 카드, 밤 메뉴, 주보, 창시 화면, HUD). Phaser 는 맵·캐릭터·색조만 그린다. 한글 도트 폰트를 DOM 에서 바로 쓰기 위해서다.
- 게임 로직(`src/sim/`)은 Phaser·DOM을 모른다 → `node tools/simulate.mjs`가 그대로 돌린다.
- 맵: Tiled JSON 형식(`src/map/*.json`). `tools/build-map.mjs`가 사람이 읽기 쉬운 배치 정의(`src/map/layout.js`)를 Tiled JSON 으로 뽑는다. 맵을 고칠 땐 layout.js 를 고치고 다시 뽑는다. Tiled 에서 직접 열어 고쳐도 된다.
- 저장: localStorage `cult-town-save`, `saveVersion` + 마이그레이션 표.
- 모든 수치는 `src/config.js` 한 곳. 문장은 `src/data/` 아래 JS 로 분리 (문장만 고치기 쉽게).
- 소스 `cult-town/`, 빌드 결과는 **레포 루트 `cult/`** (`base: './'`) → GitHub Pages `test/cult/`.

```bash
cd cult-town
npm install
npm run dev         # 개발 서버
npm run build       # ../cult/ 로 빌드
npm run map         # layout.js·interiors.js → town.json, sanctuary-*.json · layout-bongcheon.js → bongcheon.json
npm run sim         # 주민 일과 검사 + 1단계 성공률 · 2단계 도달 시간 (--games N, --verbose, --no-balance)
npm run lint:words  # 문장 금지 패턴 개수
```

## 5. 동네 (신림동 한 구역)
- 실제 큰길 이름: **남부순환로**(가로, 맵 위쪽), **신림로**(세로, 맵 가운데), **도림천**(맵 위쪽 가장자리 물길), **신림역**(두 길이 만나는 곳, 출구 2개).
- 도로 배치는 실제 동네 구조를 손으로 단순화한 것이다 (역 앞 큰 교차로, 역 남서쪽 상가 골목, 시장 골목, 남쪽 언덕 원룸촌). 정확한 지도가 아니다.
  - OpenStreetMap 은 이 환경에서 접속이 막혀 데이터를 쓰지 못했다. 나중에 OSM 데이터로 다듬으면 크레딧 화면에 "© OpenStreetMap contributors (ODbL)"을 넣는다. 지금은 넣지 않는다 (쓰지 않은 출처를 표기하지 않는다).
- 장소: 역 출구 앞 상가 골목 · 원룸촌 골목 · 전통시장 · 편의점 · PC방 · 고시원 · 작은 공원 · 동네 교회 1곳 · 작은 절 1곳 · 점집 1곳 · **성소**(역 근처 상가 건물 3층 한 칸, 실내 맵).
- 이름은 전부 창작 (예: 교회 "신림소망교회"처럼 흔한 조합도 실존 가능성이 있어 피한다 → 실존 검색이 어려운 조합으로 짓는다).

## 6. 시간
- 게임 1일 = 실제 약 **5분 25초** (07:00~21:00 낮 14시간 = 280초, 1초 = 3게임분, + 밤 메뉴 약 45초). 일시정지·2배속. 걷는 속도는 시계와 따로 칸/초로 정한다 (21장).
- 시간대: 아침(07–11) · 낮(11–17) · 저녁(17–21) · 밤(21–). 색조가 바뀌고 주민 위치가 일과대로 바뀐다.
- 21:00 이 되면 성소로 돌아가라는 알림. 22:00 까지 안 들어가면 피곤한 채로 자동 귀가(피로 페널티).
- 밤은 실시간이 아니라 **메뉴 턴**: 예배(수·일) · 소품 사기 · 신도 돌보기 · 장부 · 잠자기(다음 날 07:00).
- **실제 달력**: 2026년 3월 2일 월요일(새 학기)부터 하루씩 (`sim/clock.js`, `CALENDAR`). HUD 는 휴대폰 잠금화면처럼 "3월 4일 수요일 / 오전 9:40 / 맑음 12°". 월세·관리비는 매달 25일 밤, 주간 지출(전단·보리차·전기료)은 일요일 밤. 단계 하나 = 한 달 (그달 25일 월세까지). 요일·예배(수·일)·주보(일요일)는 7일 주기.
- 계절(`season`)·행사(`holidayOf`): 3월 개강 · 4월 도림천 벚꽃 · 5월 연휴·부처님오신날 · 6~7월 장마 · 9월 추석 · 12월 연말. 달마다 기온·비 확률·주민 고민·옷 색이 바뀐다.

## 7. 주민 30명 (심즈)
- 각자: 이름, 나이, 직업, 성격(3개 중 고름: 다정·까칠·소심·수다·계산적 등), 말투(lines.js 의 스타일 키), 종교 배경(개신교·천주교·불교·민간신앙·무교), 집, 하루 일과(시간 → 장소), 관계(가족·친구·동료), 외형(몸 틀·머리·색).
- 욕구 5개 (0~100, 높을수록 그 고민이 큼): **외로움 · 돈 걱정 · 건강 · 미래 불안 · 의미**. 시간·요일·사건에 따라 오르내리고, 매일 아침 그날의 "지금 고민"(가장 큰 욕구)이 정해진다.
- 우리 교단과의 관계: **호감**(0~100) · **의심**(0~100) · 상태 `무관심 → 관심 → 방문자 → 새신자 → 신도`.
- 관계망: 친구·가족·동료. 신도가 된 사람의 지인은 첫 대화 호감 보너스. 가족은 반대할 수 있다(가족 중 신도가 생기면 다른 가족의 의심이 오른다).
- **여론 주도 주민 3명**: 통장님, 시장 반찬가게 사장님, 약국 약사. 이들의 의심이 높으면 동네 평판이 빠르게 떨어진다.
- 주민을 누르면 **프로필 카드**: 지금 고민, 종교, 관계, 우리 교단에 대한 인상(말로), 상태.
- 일과 이동은 격자 A*. 같은 칸에 여러 명이 겹쳐도 막히지 않는다(통과 가능). 바깥 자리는 사람마다 한두 칸씩 비켜 선다.
- **일과 시각은 도착 시각**이다. 걸리는 시간(길 길이 ÷ 걷는 속도 + 3분)만큼 먼저 나선다. 시뮬레이터가 '앞 장소에 10분 이상 머무는가', '모두 도착하는가', '밤에 다 귀가하는가', '한 칸에 4명 넘게 몰리지 않는가'를 검사한다.
- 건물 안(사무실·학원·PC방 등)에 있는 주민은 화면에 안 보이고 말을 걸 수 없다. 가게 주인은 가게 앞 바깥 자리에 서 있다.
- 성직자 3명(목사·스님·만신)도 맵에 서 있다. 말을 걸면 진지한 대화만 한다 (포교 선택지 없음).

## 8. 포교 (RPG 대화)
- 말 걸기 → 선택지 3~4개 → 주민 반응(말투별 대사) + 호감·의심 변화.
- 선택지 종류: **안부 잡담**(안전, 조금) · **고민 들어주기 [고민 카드]**(지금 고민과 맞으면 크게, 틀리면 조금) · **교단 얘기 꺼내기**(호감이 높거나 같은 계열이면 통함, 아니면 의심) · **성소 초대**(호감 기준 이상) · 유형별 특기 1개.
- 같은 사람과 하루 한 번만 대화. 교주 **피로**가 하루 대화 횟수를 막는다.
- **같은 계열 보너스**: 내 교단 계열과 같은 종교 배경 주민은 호감이 쉽게 오른다. 대신 그 종교 주민들의 평균 의심이 기준(우리와 같은 계열이면 기준 × 0.8)을 넘으면 그 종교 인물(목사·스님·만신)이 개입한다: 신자들에게 경고 → 그 종교 주민 의심 일괄 상승, 동네 평판 하락. 세 인물 모두 같은 규칙.
- 무교 주민은 종교색 없는 고민(외로움·자기계발·건강)으로만 잘 통한다. 교단 얘기를 일찍 꺼내면 의심이 크게 오른다.
- 단계: 호감 ≥ 관심 기준 → **관심** · 초대 수락 → 다음 날 일과에 성소 방문 → **방문자** · 예배 1회 참석 → **새신자** · 예배 2회 + 호감 기준 → **신도**.
- 신도가 되면 주말마다 지인을 데려와 **이름 없는 신도**("따라온 사람")가 늘 수 있다. 목표 신도 수는 이름 있는 신도 + 따라온 사람.

## 9. 성소 경영 (밤)
- 상가 3층 한 칸: 예배 공간, 상담 의자, 작은 사무 책상 (Roguelike Indoors 타일).
- 예배: **수요일 밤·일요일 밤**. 참석 인원에 따라 참석자 믿음 상승 + 헌금. 수용 인원은 소품(의자·방석)이 정한다.
- 소품: 접이식 의자, 방석, 현수막, 전기포트, 형광등, 화이트보드 … 수용 인원·분위기(헌금·의심 완화)를 올린다.
- 월세: 매달 25일 밤에 빠져나간다 (월세 50만 + 관리비 10만). 못 내면 체납 1회 + 건물주 이벤트. 두 달 밀리면 쫓겨남(실패). 주간 지출은 일요일 밤.

## 18. 1단계 보강 (A)
### A-1. 동네 밀도
- 넓은 길은 **남부순환로·신림로**만 (4칸). 나머지는 차 한 대 지나갈 **2칸 골목**, 일부는 1칸 샛길과 막다른 골목.
- 건물은 작고 촘촘하게 (가로 3~6칸). 종류: `villa`(원룸 빌라) · `mixed`(1층 가게 + 위층 주거) · `mall`(상가, 여러 층 간판) · 특수(교회·절·점집·시장·공원).
- `layout.js` 는 '줄(row)' 단위로 건물을 늘어놓는다: `row(y, h, x, [...])`. 건물이 없는 칸은 골목. 그래서 지름길과 막다른 골목이 자연스럽게 생긴다.
- 1층 가게마다 간판 (`data/shops.js`, 전부 창작 이름): 편의점·치킨집·노래방·부동산·휴대폰 가게·순댓국집·미용실·코인빨래방·김밥집·세탁소·약국·PC방 등.
- 골목 소품: 전봇대와 전선, 골목 주차 차량, 화분, 분리수거함, 에어컨 실외기, 자전거. 지붕: 물탱크·실외기·빨래줄 (모두 도형, 스프라이트 키로 교체 가능).
- 글자 겹침 금지: 간판은 건물 정면에만, 바닥 글자(길 이름)는 소품·사람 자리가 아닌 빈 칸에만 (build-map 이 검사).
- 모바일: 화면 왼쪽 아래 **방향키 패드** (터치 기기에서만). 누른 곳으로 걷기도 그대로.

- 선택지: 기본 3개(안부 잡담 · 고민 들어주기 · 교단 얘기/초대) + 유형 특기 + **상황 선택지 1~2개** (사연 듣기 · 부탁 전하기 · 선물 · 점심 같이 · 우산 씌워 주기 · 장 같이 보기 · 같이 걷기 · 커피 건네기 …). 지금 고민·사연 단계·시간대·장소·날씨로 고른다.
- 선물: 편의점·시장에서 산 물건 (`data/items.js`). 사람마다 좋아하는 것·싫어하는 것이 있다.
- 반복: 같은 사람에게 바로 전과 같은 화제를 쓰면 효과 절반 + "또 그 얘기예요?" (`LINES[voice].again`).

### A-4. 난이도·타이틀
- 정석 봇 승률 **60~80%** 를 목표로 조정. 돌발 사건 주 1~2회 (`data/events.js`): 건물주 방문 · 반상회 안건 · 신도 가족 전화 · 교회 전도 행사와 겹침 · 소방 점검 · 비 오는 예배 등. 사건마다 선택지 2~3개.
- 타이틀 화면: 밤의 신림역 3번 출구 앞, 상가 3층 302호 창문에만 형광등. 실제 동네 맵을 밤 색조로 그리고 그 위에 메뉴.

### 공간 (같은 상가 건물 안) `state.space`
| 단계 | 칸 | 보증금 | 월세 | 실내 맵 |

### 방 `state.rooms[slot] = { type, level, dark }`
- 칸마다 정해진 자리(slot)에 방 하나를 고른다. 자유 배치는 하지 않는다. 302호는 처음부터 예배실.
- 종류: 예배실(수용 인원) · 상담실(방문 약속→새신자 전환↑, 초대 수락↑) · 공부방(신도 믿음↑, 교리 이름은 유형별 창작) · 주방·식당(결속↑, 따라온 사람↑) · 숙소(이탈 크게↓, 가족 항의·평판 위험↑) · 방송실(SNS 포교: 동네 밖에서 방문자 유입, 노출↑) · 사무실(헌금↑, 횡령 사건 무대).
- 업그레이드 2단계. 일부는 어두운 업그레이드(효율↑, 그림자 장부↑).
- 방 안에 신도들이 앉아 있고 돌아다닌다.

### 간부 `state.officers[]`
- 첫 신도 3명(엄마·오랜 친구·우연히 온 사람)이 첫 간부. 신도 중에서 승진시켜 최대 6명.
- 능력치: **말솜씨 · 관리 · 충성** (1~5). 성격(실수 종류)과 고유 사연.
- 배치: 방 담당(그 방 효율↑) 또는 **낮 포교** (맵을 돌아다니며 주민에게 말을 건다. 성격에 따라 실수: 의심↑).
- 간부끼리 관계(친함·앙숙), **불만** 0~100. 50 횡령 · 70 파벌(신도 일부가 따라 흔들림) · 90 이탈 (나중에 폭로: 평판 급락).
- 밤 메뉴 "간부 회의": 간부가 안건을 올리고 교주가 정한다 (불만·능력·돈·그림자 장부가 움직인다).

### 성장 연출
- 신도 50명·100명 문턱마다 faith-game 의 계시 연출(암전 → 빛줄기 → 내레이션 → 선택)을 가져온다 (`ui/revelation.js`).
- 50명: "간판" (교단을 동네에 어떻게 보일지 고르기). 100명: "울타리" (사람들이 쉽게 안 나가게 하는 규칙 고르기, 이 게임의 방·규칙으로 다시 씀). 어두운 규칙은 그림자 장부.

### 2단계 목표·실패
- 목표: **신도 100명 + 3층 전체 임대 + 간부 3명 이상**.
- 실패: 1단계 실패 조건 + **간부 과반 이탈** + **건물주 퇴거 통보** (가족 항의·소음·체납이 쌓인 `landlordAnger` 100).
- 검증: 정석 봇이 2단계 목표까지 2시간~3시간 15분 (하루 ≈ 5분 25초 → 23~36일). 하루가 길어져 2단계 끝은 3시간 남짓이다. 신도는 일요일마다 '따라온 사람'으로 크게 늘어서 목표 날짜가 주 단위(28·35일)로 몰린다.

## 21. 사용자 피드백 수정 (3단계 전)
### 뒤로가기
- 대화 안의 하위 화면(고민 카드·선물 고르기)과 밤 메뉴의 하위 화면(소품·공간·방·간부·회의·장부·라이벌) 전부 '뒤로' 버튼.
- 뒤로는 '아무것도 고르지 않은 것'이다: 대화 횟수·피로·호감·돈이 바뀌지 않는다.
- Esc 와 마우스 오른쪽 클릭 = 한 단계 뒤로 (`app.back()` 이 화면마다 등록된 뒤로 함수를 하나씩 꺼낸다). 더 뒤로 갈 곳이 없으면 Esc 는 메뉴.

### 단축키 (PC) — 전부 `e.code` 로 판정 (한글 입력 상태에서도 동작)
| 키 | code | 동작 |
|---|---|---|
| ` | Backquote | 멈춤 |
| 1 | Digit1 | 재생 |
| 2 | Digit2 | 빨리감기 |
| N | KeyN | 부탁 수첩 |

| Space·Enter | Space·Enter | 말 걸기·들어가기 |

- HUD 버튼에 단축키를 같이 적고, 메뉴에 표.

### 골목 소품
- 전봇대는 골목 뒷줄 너머 **건물 칸(원래 못 걷는 칸)** 에 세운다. 위쪽 두 칸은 사람보다 위에 그려져 뒤를 지나가면 가려진다.
- 차·화분·분리수거함·자전거는 2칸 골목의 **한쪽 가장자리(뒷줄)** 에만, 1칸 샛길과 샛길 입구 양옆에는 놓지 않는다. 실외기는 건물 벽 장식(충돌 없음).
- build-map 검사: 모든 골목 칸 기둥마다 걸을 수 있는 칸 1개 이상 · 소품 때문에 새로 생긴 막다른 칸 0개 · 결과를 출력한다.

### 걷기
- 화면 속 걷는 속도는 **현실 1초당 칸 수** 로 정한다 (1배속 기준, 2배속이면 2배).
  - 주민 기본 2.0칸/초 · 어르신(60세+) 1.4~1.7 · 청년·급한 직장인 2.2~2.6 · 비 오는 날 ×1.15 · 밤늦은 귀가(20시+) ×0.85
  - 교주 걷기 3칸/초 · 달리기 4.5칸/초 (Shift, 모바일은 방향키를 길게 누르기). 달리면 피로가 조금 더.
- 게임 시계는 1초 = 3게임분 (낮 4분 40초 + 밤 ≈ 5분 25초). 달력은 실제 날짜 (6장). 시뮬레이터용 속도 = 칸/초 ÷ 3 (칸/게임분). 일과는 이 속도로 다시 계산하고, 안 맞는 일과 시각은 고친다 (도착 전 다음 일과로 넘어간 경우 0 유지).
- 자연스러운 움직임 (화면): 출발·정지 가감속(목표 위치를 부드럽게 따라감) → 모퉁이를 살짝 돌아 걷는다 · 걸음 애니메이션 속도 = 실제 이동 속도 · 마주치면 옆으로 비켜 지나감 · 도착하면 잠깐 두리번거린 뒤 행동.
- 가는 길에 가끔 멈춤 (시뮬레이션): 폰 확인 · 가게 쳐다보기 · 횡단보도 신호 기다리기 (현실 2~4초). 걸리는 시간 계산에 기대값을 넣는다.
- 좁은 길(1칸)에서 마주치면 한쪽이 잠깐 멈춘다 (시뮬레이션).
- 간부·기자·라이벌 전도자 등 모든 NPC 가 같은 규칙 (`sim/residents.js` 의 `peopleOf`).

## 22. 3단계: 바깥의 위협
2단계 목표를 채우면 '2단계 끝' 장면 → 3단계 (`state.phase = 3`). 위협은 숫자가 아니라 **동네 맵의 사람과 물건** 으로 나타나고, RPG 로 직접 대응한다. 원칙: 실제 피해를 연상시키는 구체적 묘사 금지. 탈퇴자·기자의 말은 "돈", "시간", "가족" 수준.

### 노출 `state.exposure` (0~100)
- 평판이 낮을수록, 방송실·숙소가 있을수록, 어두운 선택·탈퇴자 수다·라이벌 폭로로 오른다. 기자 등장의 조건.

### 기자 (`x:reporter`, 창작 매체 "관악생활신문")
- 노출 40 이상이면 동네에 나타나 바깥 자리를 돌며 주민을 인터뷰한다 (질문 말풍선). 다음에 찾아갈 사람 머리 위에 '취재' 표시.
- 기자 앞쪽 시야(바라보는 방향 4칸, 폭 3칸)에 교주가 들어가면 따라온다. 시야에서 6초 벗어나면 놓친다. 붙잡히면 인터뷰.
- 인터뷰 선택: 정면 대응 · 노코멘트 · 간부를 대신 내보내기 (간부 말솜씨·성격). 결과는 3일 뒤 '뉴스 보도' (평판·노출·신도 의심).
- 기자가 신도·탈퇴자와 접촉하면 보도 수위가 오른다. 그 전에 그 사람과 먼저 얘기하면 접촉해도 수위가 오르지 않는다.

### 신도 가족 시위
- 숙소가 있거나 예배가 늦게 끝난 날, 신도의 가족(관계망의 실제 주민) 의심이 50 이상이면 다음 날 성소 입구 앞에서 피켓 시위.
- 시위 중: 그날 방문자↓ · 입구 근처를 지나는 주민 의심↑.
- 대응 (시위하는 가족에게 말 걸기): 가족 면담(신도 일부가 집으로 돌아가고 시위 해산) · 무시 · 간부 보내기(성격에 따라 악화).

### 탈퇴자
- 떠난 신도·간부는 동네에 남아 탈퇴자가 된다 (머리 위 표시).
- 다른 주민과 같은 자리에 서면 우리 얘기를 한다 (말풍선, 그 주민 의심↑).
- 탈퇴자 2명 이상 → 주말 공원·카페 모임. 모임이 3명 이상이면 기자와 연결 (노출↑).
- 대응: 찾아가 화해 (호감·사연 단계에 따라) · 피한다 · 어두운 선택 "입막음 봉투" (그림자 장부).

### 기성 종교의 공개 대응 (세 계열 같은 규칙)
- 우리 신도 중 그 종교 출신이 3명 이상이면: 교회 외벽 경고 현수막 · 절 법회 안내문 · 점집 앞 안내문이 맵에 붙는다.
- 그 종교 신자 주민 의심 일괄↑ · 그 장소 근처(6칸)에서 포교 호감 ×0.7. 품위 있고 진지한 문구.

### 라이벌 교단
- 3단계 시작 3일 뒤 생긴다. 플레이어와 다른 유형 하나, 이름·교주 창작. 서로 상대를 사이비라고 부른다 (블랙코미디).
- 라이벌 교주와 전도자 2명(`v:*`)이 맵을 돌며 같은 포교 규칙(유형 효과 포함)으로 주민에게 말을 건다. 주민마다 `rlike`·`rival` ('none'|'lean'|'member'). 프로필 카드에 "어느 쪽에 끌리는지".
- 우리 신도를 빼가기도 한다. 대응 (밤 메뉴 '라이벌'): 경쟁(평소대로 더 잘 챙기기) · 폭로(라이벌 신도에게 들은 얘기 3개 → 기자에게, 우리 노출도↑) · 합병 제안(크기 비율로 성공, 실패하면 앙숙) · 휴전.
- 정리 = 흡수 · 몰락(라이벌 규모 10 미만) · 휴전.

### 행정
- 민원(건물주 불만·가족 항의) 누적 → 구청 점검 · 소방 점검. 숙소·방송실이 있으면 위험↑ (방 단계 하락·과태료). 경찰은 순찰 강화(며칠간 예배 참석↓)까지만.

### 계시
- "카메라": 신도 150명 또는 첫 보도 (언론 대응 기조). "이웃": 라이벌 등장 때 (라이벌을 대하는 기조).

### 3단계 목표·실패
- 목표: 신도 200명 + 동네 평판 40 이상 (최근 7일 최저 30 이상) + 라이벌 정리.
- 실패: 기존 조건 + 보도 누적으로 평판 바닥 + 우리 신도 과반이 라이벌로 이동.
- 검증: 정석 봇 3단계 성공률 60~80%, 3단계 시작부터 목표까지 2~3시간. 라이벌 AI 는 플레이어가 아무것도 안 해도 신도를 모은다.

### 구현 메모 (지금 값, 수치는 config.js PHASE3 · EXPOSURE · REPORTER · PROTEST · DEFECTOR · NOTICE · RIVAL · ADMIN)
- 노출: 매일 목표치 쪽으로 30%. 목표치 = 18 + (60 − 평판)×0.6 + 신도 수×0.12 + 숙소·방송실 레벨 + 탈퇴자 + 최근 5일 어두운 선택 + 큰 탈퇴자 모임 + 라이벌 폭로. 보도 직후 4일은 내려간다.
- 기자는 한 시간마다 자기 자리 근처 주민 한 명에게 묻는다 (`threatHour` → `reporterHour`). 동네 3일 → 떠나고 3일 뒤 보도 → 쿨다운 5일. 인터뷰를 따면 다음 날 떠난다. 피하기만 하면 하루마다 열기 +3.
- 보도: 열기 15 미만 짧은 기사 · 35 미만 사회면 · 그 이상 1면. 평판 −(열기/2.2 + 5), 신도 의심↑, 따라온 사람 일부 이탈. 보도 2번 이상 + 평판 32 이하면 실패('press').
- 시위: 가족 면담 = 그 신도가 새신자로 내려가고 시위 끝 · 무시 = 반쯤 다음 날 또 나옴, 두 번 무시하면 순찰 3일 · 간부 = 관리 4 이상이면 해산.
- 탈퇴자: 떠난 신도·주민 출신 간부. 한 시간마다 같은 장소 주민에게 수다(하루 3번까지, 의심 +3). 토요일 14~16시 솔밭 쉼터 모임(2명 이상), 3명 이상이면 기자 열기 +8. 입막음 봉투는 6일 뒤 평판 −8·노출 +10.
- 라이벌: 3단계 4일째 등장, 규모 30에서 시작. 교주·전도자 셋이 한 시간마다 ⅓ 확률로 근처 주민에게 말 걸기. 매일 +1, 일요일 +(라이벌 신도×1.2 + 8), 일요일마다 우리 따라온 사람 중 12%×(저쪽/우리)를 가져간다. 우리가 그 주민에게 말을 걸면 라이벌 호감이 식는다.
- 합병·휴전은 라이벌이 생기고 9일 뒤부터 받아 준다. 합병 확률 = (우리−저쪽)/(합)×0.8 + 평판/400 − 0.25 (앙숙 −0.3). 휴전 = 우리가 1.3배 이상일 때 0.1 + 평판/400 + (배율−1.3)×0.05. 폭로 = 들은 얘기 3개, 저쪽 절반 감소·10일 성장 멈춤·앙숙·우리 노출↑. 경쟁 = 3일 동안 저쪽 포교 ×0.55, 하루 2명씩 우리 쪽으로.
- 행정: 민원 30 쌓이면 반쯤 확률로 다음 아침 구청·소방 점검 (아침 돌발 사건 형식). 협조 = 숙소·방송실이 있으면 65% 확률로 방 한 단계↓ + 과태료 15만 원. 미루기 = 4일 뒤 과태료 두 배.
- 정석 봇 3단계: 시위는 간부(관리 4+) 아니면 가족 면담, 보이는 탈퇴자와 화해, 기자가 있으면 신도부터 만나고 인터뷰는 말 잘하는 간부 · 평판 65+면 정면 · 아니면 노코멘트, 라이벌은 합병(55%+) → 휴전(35%+) → 폭로 → 경쟁, 계시는 장부 공개·먼저 인사.

## 23. 4단계: 옆 동네 — 봉천동 지부
3단계 목표를 채우면 '3단계 끝' 장면 → 4단계 (`state.phase = 4`).

- **맵 두 장**: 신림동(`town.json`) + 봉천동(`bongcheon.json`). 봉천동 실제 이름: 서울대입구역(2호선), 관악로(세로 큰길), 남부순환로(가로). 언덕 원룸·고시촌, 먹자골목, 상가. 가게·건물·인물 이름은 전부 창작. build-map 은 레이아웃마다 돌고, 통행 검사도 두 맵 다.
- **이동**: 신림역·서울대입구역 입구에서 '2호선 타기' (게임 20분, 1,400원). `state.district` = 'sillim' | 'bongcheon'. 밤 메뉴는 늘 302호 (21시 알림·22시 자동 귀가 그대로, 봉천동에 있으면 지하철로 돌아온다).

- **평판은 동네마다** (신림동 `s.rep` · 봉천동 `s.repB`). 말 걸기 거절·성직자 개입·공개 안내문·노출은 그 동네 기준.

- **3단계 위협 계속**: 기자는 노출 높은 동네에 나온다. 라이벌이 정리되지 않았으면 봉천동에도 전도자를 보낸다. 시위·탈퇴자·안내문은 동네마다.
- **새 위협 — 지부장**: 지부장 불만이 쌓이면 지부를 들고 독립하려 한다 (예고 → 대응: 면담·권한 주기·교체). 실패하면 분열.
- **계시 V '지부'**: 지부를 열 때 운영 기조를 정한다.
- **목표**: 신도 350 + 봉천 지부 신도 100 + 두 동네 평판 모두 40 이상. **실패**: 기존 조건 + 지부 분열 + 봉천동 평판 바닥.

## 24. 재미 보강 · 대사 전면 수정 · 퀘스트 · 열혈 신자 · 날짜 체계

### A. 바로 고칠 것
1. **실제 달력** (6장을 대체): 2026년 3월 2일 월요일(새 학기)부터 하루씩. HUD 는 휴대폰 잠금화면처럼 "3월 4일 수요일 · 오전 9:40 · 맑음 12°".
   - 압축 달력(한 달 = 5일)을 없앤다. 월세·관리비는 **매달 25일**, 실제 한 달 금액. 대신 **주간 지출**(전단 인쇄·보리차·전기료·교통비)이 일요일 밤에 나가 돈 압박을 유지한다.
   - 1단계 목표: 신도 30 + **첫 월세(3월 25일) 납부**. 체납은 두 달이면 쫓겨남.
   - 계절: 3월 개강 · 4월 벚꽃(도림천) · 5월 연휴 · 6~7월 장마 · 9월 추석 · 12월 연말. 달마다 기온·비 확률·주민 고민(외로움·미래·건강)·계절 사건이 바뀐다. 주민 옷 색도 계절에 맞게 살짝 (3월 두꺼운 겉옷 → 5월 밝게 → 장마 어둡게).
   - 주보는 매주 일요일 그대로. 예배는 수·일.
2. **성소 간판**: 동림상가 입구 층별 안내판(1층 꼬마김밥 · 2층 보습교실 · 3층 302호 [교단 이름] · 4층 쿵탁탁구장) · 302호 문 앞 안내문.
   - 간판 단계 (밤 메뉴 '간판', 돈을 들인 업그레이드): 0 A4 종이 테이프 → 1 창문 시트지 글씨 → 2 아크릴 간판 → 3 외벽 대형 간판 + 저녁 조명. 단계마다 평판·초대 수락 소폭↑, 노출↑.
   - 맵에서 '302호'로 보이던 곳은 교단 이름. 주민 대사는 `{성소}` 로 쓰고, 간판 단계 0~1 이면 "302호", 2 이상이면 교단 이름으로 부른다.
3. **글자 겹침**: 역 출구 표지·주민 자리가 겹치지 않게 자리를 옮긴다. build-map 검사에 **글자-사람 자리 겹침**, **간판끼리 간격**을 넣고 결과를 출력 (둘 다 0).
4. **대화 선택지 설명**: 수치 설명 대신 짧은 행동 묘사 ("날씨, 동네 얘기"). 정확한 효과는 대화창 (i) 버튼 또는 선택지 길게 누르기에서만.
5. 시뮬레이터: 실제 달력 기준으로 다시 맞춘다 (재림 교주형·신내림 점집 확장형 3단계는 #230 에서 이미 60~80%·2~3시간).

### B. 대사 전면 수정 (lines · stories · gossip · events · threats · officers · cast · clergy · rival · bulletin · residents-bongcheon)
- 지금 대사가 AI 같은 이유를 고친다:
  - 처음 본 사람에게 속마음을 털어놓지 않는다. 친해지기 전엔 얼버무리고 딴소리. 속마음은 호감이 높을 때만, 조금씩.
  - 숫자는 그 사람이 진짜 신경 쓰는 것 하나만. 나머지는 "꽤", "한참", "몇 년".
  - 대부분은 평범하게 끝난다. 웃긴 마무리는 그 사람 성격에 맞을 때만.
  - 말줄임표(…)는 한 사람당 가끔만.
  - 지문을 줄이고, 쓸 때도 형태를 섞는다 ("OOO가 ~한다." 한 가지 틀 금지).
  - 사람마다 말이 끊기고, 같은 말을 반복하고, 주어를 빼먹고, 엉뚱한 대답. 어르신은 반말 섞인 존댓말, 20대는 줄임말, 사투리 쓰는 주민 2~3명.
  - 모두가 성실히 반응하지 않는다: 폰 보며 건성으로, 바쁘다고 끊기, 자기 얘기만 하는 사람.

### C. 퀘스트
1. **메인 퀘스트**: 단계마다 3~6개 연결된 목표 + 짧은 장면 + 보상(돈·교주 경험치·기능 해금). 1단계 "개업": 간판 달기 → 전단 붙일 자리 3곳 → 통장님께 인사 → 첫 예배 5명 → 첫 월세. 2·3·4단계도 기존 목표를 퀘스트로 쪼갠다.
2. **사연 갈림길**: 주민 사연 마지막 단계에 선택 2~3개 (예: 연락을 이어 준다 · 교단 기도회로 끌어온다(그림자 장부) · 모른 척). 결과는 며칠 뒤 그 주민의 삶에 나타난다 (장면 이벤트).
3. **오늘의 할 일**: 매일 아침 수첩에 작은 일 3개 (신도·간부·주민·사건에서 뽑음). 하면 소소한 보상, 안 하면 작은 불만.
4. **수첩 UI**: 메인 / 사연 / 오늘 / 엿들은 소문 탭. 목표 장소·사람을 맵에 표시.

### C 구현 메모 (지금 값, config.js QUEST)
- 메인 퀘스트 `s.quest = { phase, step, flyers, tong, maxAttend, visitedB, news }`. 조건은 sim/quests.js `DONE` (단계 목표의 길을 쪼갠 것이라 목표 판정은 그대로). 끝낸 단계는 `news` 에 쌓이고 화면이 아침·대화 뒤에 장면으로 보여 준다. 보상은 경험치·작은 돈·평판.
- 전단: 메인 단계가 '전단'일 때 편의점·시장·역·공원·산책로 입구에 가면 붙는다 (`visitSpot`). 통장님께 인사: 그 단계에서 정순자와 아무 대화.
- 사연 갈림길: 세 번째 부탁을 끝낸 주민은 `fork = 'pending'` → 다시 말을 걸면 '그 뒤의 얘기' 선택지. 곁에 있어 준다(3일 뒤 평판+1) · 성소 일을 맡긴다(호감 크게↑, 광신 쪽, 5일 뒤 가족·친구 의심 +12, 어두운 선택으로 셈) · 진짜 도움을 알려 준다(고민마다 이름: 구청 복지 상담·보건소·청년센터·동네 모임·원래 다니던 곳 / 의심↓, 4일 뒤 평판+3). `s.later` 가 며칠 뒤 결과를 낸다.
- 오늘의 할 일: 아침마다 셋 (게임 난수 안 씀). 하나마다 경험치, 셋 다 하면 1만 원. 하나도 안 하면 첫 신도 의심 +1.
- 엿들은 소문: 가까이서 들린 수다 중 우리 얘기·다른 주민 이름이 나오는 것만 `s.heard` (30개).
- 지도 느낌표: 노랑 메인 · 초록 부탁 · 파랑 오늘 · 분홍 사연의 끝 (`questMarkers`).
- 정석 봇: 전단 세 곳 · 오늘 '둘러보기'는 지나는 길에 (피로 +1) · 간판 첫 단계는 월세 여유가 있으면 · 갈림길은 '곁에 있어 준다' (열혈 봇은 '맡긴다').

### D. 새 재미 요소
1. **예배 미니게임**: 성소 실내에서 참석자 얼굴 상태(졸음·감동·의심·폰). 설교 화제 카드 3~4장을 순서대로 → 참석자 고민과 맞을수록·앞 카드와 이어질수록 분위기 게이지↑ → 반응 말풍선·헌금·믿음. 대박이면 주보 1면. 설교는 유형별 창작 교리로 블랙코미디, 실제 설득 화법은 쓰지 않는다 (카드 이름과 결과만).
2. **열혈 신자**: 믿음 높은 신도를 지정(또는 조건에서 자동). 낮에 자기 관계망부터 알아서 포교, 맵에서 걷고 말 거는 게 보인다. 배치·통제 불가. 성격별 사고: 들이대기(의심↑) · 가족과 싸움(시위 유발) · 몰래 헌금 걷기(그림자 장부) · 라이벌과 말다툼. 많을수록 빠르고 사고도 잦다. 밤 메뉴 '진정시키기'.
3. **교주 성장**: 경험치·레벨. 능력 5개 말솜씨·체력·카리스마·눈치(의심 대략 보임)·위장(기자·탈퇴자 시야↓). 레벨마다 하나. 새 선택지·행동 해금 (카리스마 3 → 길거리 즉석 설교). 사기↔광신 축에 따라 해금이 갈린다.
4. **동네 드라마**: 주민끼리 연애 시작·바람 소문·부부 싸움·화해·이사·합격·폐업·개업. 고민·관계망이 바뀌고 말풍선·소문·주보로 보인다. 교주는 이용(그림자 장부)·위로·모른 척. 주민끼리만 (0장).
5. **결정적 순간 연출**: 신도가 되는 순간 컷인 + 그 사람 한 줄 · 라이벌에게 뺏길 때 전단 들고 성소 앞을 지나가는 장면 · 간부 승진 · 첫 열혈 신자 · 간판 교체.
6. **엿듣기**: 가까이서 들은 말풍선 대화 → 수첩 '엿들은 소문' → 대화에 새 선택지.

### D 구현 메모 (지금 값, config.js GROWTH · ZEALOT · DRAMA · SERMON · TIP)
- **예배 미니게임** (`sim/sermon.js`, `ui/worship.js`, `data/sermons.js`): 유형마다 창작 교리 카드 6장, 그날 손패 4장(날짜로 정해짐) 중 3장을 순서대로. 카드가 고민에 닿은 참석자는 '감동' 얼굴, 게이지 += 닿은 비율×40 + 앞 카드와 흐름(tag)이 같으면 12. 점수 0~1 → 믿음·헌금 ×(0.8~1.15). 0.8 이상이면 주보 1면 한 줄. 정석 봇은 손패에서 가장 좋은 순서.
- **열혈 신자** (`sim/zealots.js`): 호감 85+ 신도를 밤 메뉴에서 세운다 (최대 6). 호감 96+ 신도는 하루 5% 로 스스로 열혈이 된다 (첫 열혈은 컷인). 하루 끝에 관계망(신도 아닌 사람) 먼저, 모자라면 같은 동네 아무나 두 명에게 호감 +5 (관계면 ×1.5)·의심 +3 (들이대는 성격 ×1.5). 사고 하루 8%: 들이대기(의심 +15·평판 −1) · 가족과 싸움(가족 의심 +20·평판 −2) · 몰래 헌금(3만 원·어두운 선택, 4일 뒤 평판 −4) · 라이벌과 말다툼(노출 +5). '진정시키기' = 4일 사고 없음, 호감 −4. 맵에서 '열' 표시와 말풍선.
- **교주 성장** (`sim/growth.js`): 경험치 = 대화 1 · 예배 3 · 신도 5 · 퀘스트·오늘의 할 일. 다음 레벨 = 50 + 40×(레벨−1). 레벨마다 능력 1점 (밤 메뉴 '교주'). 말솜씨 호감 +4%/점 · 체력 피로 한도 +8/점 · 카리스마 예배 +4%/점, 3이면 낮에 '길거리 설교'(6칸 안 주민 호감 +4, 무교 의심 +4, 피로 25, 하루 한 번) · 눈치 단서 정확도 +6%/점, 2부터 프로필에 경계 정도 · 위장 노출 목표 −1.5/점, 3부터 기자 시야 −1칸. 레벨 3+ 믿음 축 해금: 사기(−20 이하) '후기 전단'(2만 원·평판 +3·어두운 선택) / 광신(+20 이상) '새벽 심방'(신도 호감 +4·가족 의심 +2·내일 피곤).
- **동네 드라마** (`sim/drama.js`, 게임 난수 안 씀): 하루 14% 로 한 건. 연애(친구·동료, 성인, 나이 차 8 이하) · 헤어짐 · 소문 · 다툼(가족) · 화해 · 합격/불합격(시험 준비생) · 폐업/개업(가게 주인). 고민이 바뀌고 아침 소식·엿들은 소문·주보 '동네 소식'. 그 주민과 4일 안에 대화하면 '위로하기'(호감 +7) · '끌어오기'(호감 +12, 사기 쪽, 어두운 선택, 4일 뒤 의심 +15). 주민끼리만, 묘사는 소문 수준.
- **컷인** (`ui/cutin.js`): 신도가 되는 순간(그 사람 신도 인사 한 줄) · 간부 승진 · 첫 열혈 신자 · 간판 교체 · 라이벌 쪽으로 간 사람.
- **엿듣기**: 수다 중 다른 주민 고민 얘기를 들으면 그 주민에게 `tip` → 5일 안에 대화하면 '들은 얘기 꺼내기' (맞으면 고민 카드 맞힌 것의 0.8배 호감 + 고민을 알게 됨).
- 정석 봇: 예배는 가장 좋은 카드 순서, 능력은 낮은 것부터, 열혈 한 명까지 + 나흘마다 진정, 길거리 설교, 들은 얘기·위로 우선. 열혈 봇: 열혈 여섯까지, 진정 안 함, 드라마는 끌어오기.

### 검증
- `npm run sim`: 일과 문제 0 · 실제 달력 기준 단계마다 성공 60~80%, 2~3시간 · 열혈 신자를 많이 쓰는 봇은 빠르지만 사고로 실패율↑.
- `npm run lint:words`: 기존 금지 패턴 0 + B 검사 결과 보고. `npm run map`: 글자 겹침 0.
- 직접 플레이: 3월 2일 시작 → 간판 → 오늘의 할 일 1개 → 메인 퀘스트 2개 → 예배 미니게임 → 사연 갈림길 → 열혈 신자 지정 후 알아서 포교. 같은 주민에게 사흘 연속 말 걸어 대사가 안 겹치는지. PC·모바일 스크린샷. `npm run build`.
