# 추모가요 음원

이 폴더에 음원 파일을 올리고, `assets/data/songs.json` 의 `tracks` 에 한 줄을 더하면
추모가요 페이지(`/anthem/songs/`)에 자동으로 수록된다. **페이지 HTML 은 고치지 않는다.**

## 추가하는 방법

1. mp3 파일을 이 폴더에 올린다. 예: `assets/songs/my-song.mp3`
2. `assets/data/songs.json` 의 `tracks` 배열 끝에 항목을 하나 추가한다.

```json
{
  "id": "my-song",
  "title": "곡 제목",
  "kind": "추모가요",
  "by": "민주시민",
  "sec": 195,
  "src": "songs/my-song.mp3",
  "on": "2026년 9월 20일 수록",
  "desc": "한 줄 설명. 비워 두어도 된다.",
  "link": "",
  "linkText": ""
}
```

## 항목 설명

| 키 | 뜻 |
|---|---|
| `id` | 주소 뒤에 `#id` 를 붙이면 그 곡이 선택된다. 영문·숫자·붙임표만 쓴다 |
| `title` | 목록과 재생기에 표시되는 제목 |
| `kind` | 구분. `국가` `이전 국가` `추모가요` 등 자유롭게 적는다 |
| `by` | 작사·작곡 |
| `sec` | 재생 시간(초). 목록에 먼저 보여 주는 값이며, 실제 길이를 읽으면 그 값으로 바뀐다 |
| `src` | `assets/` 아래의 경로. 국가처럼 `assets/` 바로 아래면 파일명만 적는다 |
| `on` | 수록일이나 제정일 |
| `desc` | 설명. 생략 가능 |
| `link` / `linkText` | 곡을 따로 다루는 페이지가 있으면 그 주소와 문구. 생략 가능 |

목록의 순서가 재생 순서다. 위에서부터 이어서 재생된다.
