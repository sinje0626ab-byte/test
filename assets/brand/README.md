# 국가상징 이미지

이 폴더의 파일 세 개는 아직 비어 있습니다. 아래 이름 그대로 올리면 사이트에 자동으로 붙습니다.
**파일이 없는 동안에도 사이트는 깨지지 않습니다** — 로고 자리에는 기존 촛불 이모지가,
소개 페이지 상단에는 아무것도 표시되지 않습니다.

| 파일명 | 쓰이는 곳 | 권장 사양 |
|---|---|---|
| `flag.png` | 상단 메뉴, 국호 글씨 왼쪽 | 국기 이미지. 가로형, 높이 24px로 표시되므로 **96×64px 이상**, 배경 포함 |
| `emblem.png` | 파비콘 (브라우저 탭 아이콘) | 국장 마크. **정사각형 512×512px**, 여백을 최소로 |
| `about-hero.png` | 소개 페이지 맨 위 | 국가상징 모음 이미지. 가로 **1600px 내외**, 용량 1MB 이하 권장 |

## 올리는 방법

1. GitHub 저장소에서 `assets/brand/` 폴더로 들어간다
2. **Add file → Upload files**
3. 파일을 끌어다 놓는다 (이름이 위 표와 정확히 같아야 한다)
4. 아래 **Commit changes** 를 누른다

이름이 다르면 붙지 않습니다. 대소문자와 확장자까지 그대로 맞춰 주세요.
한 번에 25MB까지 올라가며, 그보다 크면 업로드가 조용히 실패합니다.

## 파비콘에 관하여

`emblem.png` 가 올라오면 브라우저 탭 아이콘이 기존 오리에서 국장으로 바뀝니다.
파일이 없으면 오리가 그대로 남습니다 — 두 개를 함께 선언해 두었기 때문입니다.
