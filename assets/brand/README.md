# 국가상징 이미지

사이트에서 실제로 쓰이는 파일들입니다.

| 파일 | 쓰이는 곳 | 비고 |
|---|---|---|
| `flag.webp` | 상단 메뉴, 국호 글씨 왼쪽 (높이 24px) | 216×144 · 7KB |
| `favicon-flag.png` | 파비콘 | 256×256 · 국기를 정사각 캔버스 가운데 · 7KB |
| `emblem.png` | (현재 미사용) 국장 · 흰 그림 | 512×512 · 투명 배경 |
| `emblem-ink.png` | (현재 미사용) 국장 · 먹색 그림 | 512×512 · 투명 배경 |
| `about-hero.webp` | 소개 페이지 맨 위 | 1536×1024 · 266KB |
| `emblem-src.png` | (쓰이지 않음) 파비콘 원본 | 1439×1093 · 재생성용 master |

## 파비콘은 국기를 쓴다

`favicon-flag.png` 하나만 선언합니다. 국기는 감색 바탕을 스스로 가지고 있어
밝은 탭과 어두운 탭 모두에서 보이므로, 탭 색에 따라 갈라 쓸 필요가 없습니다.
16px 에서도 감색 사각형과 금색 테두리로 국기임을 알아볼 수 있습니다.

국장(`emblem*.png`)은 선 도안이라 16px 에서 작은 덩어리로 뭉개졌습니다.
지금은 쓰이지 않지만 다른 용도를 위해 남겨 둡니다.

## 원본과 재생성

`emblem-src.png` (1439×1093, 흰 그림 · 검정 배경)이 파비콘의 master 입니다.
두 파비콘은 이 파일에서 만들어집니다 — 밝기를 알파로 옮겨 배경을 투명하게 하고,
잉크 경계로 잘라 정사각형으로 맞춘 뒤 512×512 로 **줄입니다**(키우지 않습니다).

도안을 바꾸면 `emblem-src.png` 를 덮어쓰고 다시 만들면 됩니다.
`emblem-src.png` 자체는 사이트에서 쓰이지 않으므로 방문자에게 전송되지 않습니다.

16px 에서는 촛불·태극·연꽃에 외곽 호와 잎까지 들어간 세밀한 도안이라
여전히 작은 덩어리로 보입니다. 32px 이상에서는 선이 분명히 살아납니다.

## 원본 파일

업로드하신 원본(`flag.png` 1.4MB, `about-hero.png` 2.4MB)은 표시 크기에 비해
너무 커서 WebP로 줄여 쓰고 작업 폴더에서는 지웠습니다.
원본은 커밋 `7ee2f88` 에 그대로 남아 있어 언제든 다시 꺼낼 수 있습니다.

## 바꾸고 싶을 때

같은 이름으로 덮어쓰면 됩니다. 파비콘을 새로 만들 때는 정사각형,
배경 투명, 여백 최소로 512×512 PNG 를 권장합니다.
