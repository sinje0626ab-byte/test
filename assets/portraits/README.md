# 국무위원 초상 사진

이 폴더에 아래 파일명으로 사진을 올리면 국무위원 페이지(`/officials/`)의
프로필 칸에 자동으로 표시된다. 코드 수정은 필요 없다.

| 파일명 | 인물 | 직위 |
|---|---|---|
| `president.png` | 민주시민 | 대통령 |
| `vice-president.png` | 추모합니도 | 부통령 |
| `prime-minister.png` | 햄지 | 국무총리 |
| `correction-chief.png` | 베네수호자 | 추모교정국장 |
| `audit-chief.png` | 최무현 | 추모감사원장 |
| `weather-chief.png` | 어흥 | 추모기상청장 |
| `culture-minister.png` | 딸기 | 문화추모부장관 |

| `former-correction-chief.png` | 애국좌수 | 초대 추모교정국장 (전임) |

## 규칙

- 확장자는 `.png` 를 기본으로 하되, `.jpg` · `.jpeg` · `.webp` 로 올려도
  `assets/nav.js` 가 차례로 찾아서 표시한다. 파일명만 위 표와 맞추면 된다.
- 표시 영역은 가로:세로 = 3:4 비율로 잘린다. 인물의 얼굴이 위쪽 20% 지점에
  오도록 잘려서 보이므로, 전신 사진도 그대로 올리면 된다.
- 해당 파일이 없으면 기존 이모지(🕯️ 📰 🐹 ⚖️ 🔍 …)가 그대로 표시된다.
  즉 일부만 올려도 페이지가 깨지지 않는다.
- 위 9개 카드 모두 마크업이 이미 연결되어 있다. 파일만 올리면 되고,
  `officials/index.html` 을 고칠 필요는 없다.
