# 「영원하라 추모공화국」 전자책 만들기

추모공화국 홈페이지와는 별개인 독립 전자책이다. 주소는 사이트의 `forever/`이고, 추모공화국 메뉴와 연결하지 않는다.
펼친 면의 왼쪽에는 글 한 쪽, 오른쪽에는 그 쪽의 그림 한 장(세로 2:3, 동화책 그림체)이 들어간다.

## 1. 원고

- 1부~2부 1장은 작가가 쓴 글을 그대로 옮겼다.
- 2부 2장부터는 작가의 허락에 따라 재미 요소(블랙코미디 장면, 대사, 소품, 반전, 조연의 반응 등)를 더하고 문장을 다듬어도 된다. 줄거리, 인물 관계, 결말, 주요 수치와 고유명사는 그대로 둔다. 무엇을 더했고 무엇을 고쳤는지는 보고할 때 빠짐없이 적는다.
- 장 하나가 파일 하나다: `forever/src/00.md`(프롤로그), `01.md`(1장), `02.md`…. 파일 이름 순서가 책 순서다.

```
부: 1부: 추모의 제단        ← 새 부가 시작하는 장에만
장: 1장: 위기의 보고

=== 쪽
그림: 이 쪽 그림의 장면 (1~3문장)

본문 문단. 빈 줄로 문단을 나눈다. **굵게** 를 쓸 수 있다.

=== 쪽
그림: 다음 쪽 장면

다음 쪽 본문…
```

## 2. 쪽 나누기

- 한 쪽은 **공백 포함 350~480자** 정도. 짧은 대사가 많으면 문단 사이 여백 때문에 더 짧게 잡는다.
- 쪽은 문단 사이에서만 나눈다.
- 한 쪽에는 그림 한 장으로 보여 줄 장면이 하나 있어야 한다.
- 쪽의 마지막 줄은 다음 쪽을 넘기고 싶게 끊으면 좋다(문이 열리는 순간, 질문, 반전).
- 빌드 뒤 브라우저(1280×720 정도)에서 글이 쪽 안에 들어가는지 본다. 넘치면 쪽 안에서 스크롤이 생기므로 쪽을 나눈다.

## 3. 그림 장면(`그림:` 줄)

- **영어로** 쓴다(챗GPT 그림 생성은 영어 지시를 더 정확히 따른다).
- 구도, 인물, 표정, 몸짓, 빛, 소품을 구체적으로 적는다. 웃긴 장면은 과장된 몸짓과 표정으로(블랙코미디 그림책).
- 인물은 `book.json` 「등장인물」의 영어 이름(`en`) 그대로 적는다(예: `Chumo-yeolsa`, `Lee Gija`). 그러면 그 인물의 생김새가 쪽별 프롬프트에 자동으로 다시 붙는다.
- 회의실 장면은 `council hall`이라는 말을 넣는다. 그러면 장소 설명이 붙는다.
- 인물은 모두 **동물(또는 인형)** 이다. 사람은 최무현 하나뿐이다.
  - 국무위원은 국무위원 형상 시트(`forever/reference/cabinet-sheet.webp`)대로 그린다.
  - 국무위원이 아닌 인물은 성격에 맞는 동물을 골라 `book.json`에 더한다. 예: 부이 → 거북이, 이기자 → 나무늘보, 하이 → 코알라, 존푹타 → 검은 쥐.
- 생김새(`look`)에는 종, 색, 옷, 소품, 버릇만 적는다. 특정 장소나 상황은 넣지 않는다(다른 장면과 부딪힌다).
- 성별을 모르는 인물은 he/she 대신 이름이나 its로 쓴다.
- 화면, 문서, 그래프가 나오면 `(no numbers)`처럼 글씨가 없다고 적는다.
- 그림체와 공통 조건은 `book.json`에 있으므로 장면 줄에 반복하지 않는다.

## 4. 빌드

```bash
python3 forever/build.py
```

`forever/index.html`(전자책)과 `forever/PROMPTS.md`(그림 프롬프트)가 다시 만들어진다. 이 둘은 직접 고치지 않는다.

## 5. 그림

1. 챗GPT 새 대화에 참고 그림 두 장(`forever/reference/cabinet-sheet.webp`, `flag.png`)을 첨부하고 `forever/PROMPTS.md`의 「1단계」를 붙여넣는다(그림체와 인물 설정).
2. 「2단계」의 쪽별 상자를 하나씩 붙여넣어 그림을 받는다.
3. 받은 그림을 붙인다:

```bash
python3 forever/add_image.py 받은그림.png 1 3
```

이렇게 하면 1장 3쪽에 붙는다. 프롤로그는 `0`, 표지는 `cover`다. 그림을 세로 2:3으로 자르고 webp로 바꿔 `forever/images/`에 넣은 뒤 다시 빌드한다.

그림 파일 이름은 `장-쪽.webp`(예: `01-03.webp`)다. 쪽을 새로 끼워 넣으면 그 뒤 쪽 번호가 밀리므로, 이미 붙은 그림의 파일 이름도 함께 옮긴다.
