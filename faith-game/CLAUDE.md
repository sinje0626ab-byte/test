# CLAUDE.md — 사이비 교주 블랙코미디 전략 게임 (이름 미정)

> 게임 이름은 아직 정하지 않았다. 정해지면 `src/config.js`의 `GAME.title`과 `index.html`의 `<title>`만 바꾼다.

이 문서는 게임의 설계 기준이다. 설계가 바뀌면 코드보다 이 문서를 먼저 고친다.

## 0. 원칙 (어기지 않는다)
- 풍자 대상은 **플레이어가 만든 가상의 교단**뿐이다. 실존 종교(기독교·이슬람교·힌두교·불교·유대교·민간 신앙·기타·무종교)는 배경 세력으로만 두고 비하하지 않는다. 모든 조직 종교는 같은 결속 계수를 쓰고, 효과는 나라 특성(도시화·소득·자유도)에만 반응한다.
- 배경이 한국이다. 실존 사이비·신흥 단체의 이름, 교주, 사건, 교리 용어, 장소(본부가 있던 동네·건물·섬 이름 포함)를 연상시키는 표현은 쓰지 않는다. 등장인물 이름은 흔한 이름만 쓴다.
- 어두운 선택에는 반드시 나중에 돌아오는 대가가 있다. "나쁜 짓 = 공짜 이득"이 되면 안 된다 (→ 그림자 장부).
- 문장은 게임적 묘사 수준으로만 쓴다. 현실에서 따라 할 수 있는 구체적 수법·절차는 쓰지 않는다.

## 1. 개요
- 한국의 평범한 사람이 어느 날 교주가 되기로 결심하고, 가상의 교단을 동네에서 세계로 키우는 블랙코미디 턴제 전략 게임.
- **시작은 항상 대한민국(410)**이다. 시작 나라 선택은 없다. 세계 175개국 데이터와 지구본은 그대로 두고, 바다를 건너는 순간이 중반 전환점이다.
- 초반은 **계시**(스토리 장면)로 진행된다. 계시는 한 번에 몰아서 나오지 않고, 조건을 채운 턴이 끝날 때 하나씩 등장한다.
- 교단은 사람으로 굴러간다. 고정 등장인물(`story/cast.js`)이 계시와 사건에 이름으로 나오고, 떠나고 배신하고 잡혀가고 죽는다.
- 이후 세계지도(3D 지구본) 턴제 시스템이 본편이다. 1턴 = 1개월.
- 승리: 세계 인구의 30%가 신도.
- 패배: 신도 0 / 교주 체포(후계자 없음) / 교주 사망(후계자 없음, 또는 불사 선언 후 사망) / 교단 분열(결속 0).

## 2. 기술·배포
- Vite + 바닐라 JS (ES 모듈), 지도는 d3-geo(정사영 지구본)/d3-zoom + world-atlas `countries-110m`
- 국기: flag-icons(MIT) SVG를 `npm run flags`로 `public/flags/{iso2}.svg`에 복사해 함께 배포 (북키프로스·소말릴란드는 없음)
- 저장: localStorage `faith-game-save` (매 행동·매 턴 자동 저장, `saveVersion` + 마이그레이션 표)
- 레포 루트가 GitHub Pages로 서비스된다. 소스는 `faith-game/`, 빌드 결과는 **레포 루트 `faith/`** (`base: './'`). 배포물은 손으로 고치지 않고 `npm run build`로 다시 만든다.

```bash
cd faith-game
npm install
npm run dev        # 개발 서버
npm run build      # ../faith/ 로 빌드
npm run adjacency  # 국가 연결(육로·해로) 다시 계산
npm run flags      # countries.json에 iso2를 채우고 국기 SVG 복사
npm run sim        # 밸런스 표 (여러 플레이 성향 × 원칙·울타리 조합 × 시드)
node tools/simulate.mjs --policy good --seed 3 --log   # 한 판 자세히 (본거지는 늘 대한민국)
npm run lint:words # 문장 금지 패턴 개수
```

## 4. 데이터
- `countries.json`: `{ name, iso2, region, pop, urban, freedom(0~100), gdpTier(1~4), religions? }`. `religions`가 없으면 `regionDefaults[region]`(지역 평균).
- 키는 world-atlas 도형 ID(ISO 숫자). 코드 없는 도형은 `ids.js` (북키프로스 1001, 소말릴란드 1002, 코소보 383).
- `adjacency.json`: `land` 국경 공유, `sea` 해안선 650km 이내 + 수동 항로. 스크립트로만 고친다.

## 5. 핵심 규칙
### 성장
- 시작 신도 **3명**. 자연 증가율은 낮다(월 5~8% × (1−저항력) × 자유도) → 성장은 플레이어 행동(유닛·기적·성지)이 이끈다.
- 이탈 = 기본율 × (1 + 저항력 × 가중치) × 교리 × 결속 보정 × (1 − 수호자). 한 나라 신도가 1명 미만이면 0.
- 유닛 전파량 = 유닛 기본값 × 교리 보정 × (1 − 저항력) × 자유도 × **도달력** × 단계 배율
  - 도달력 = min((개종 가능 인구)^0.6, k × (전 세계 신도 + 씨앗)^지수) → 조직이 커질수록 유닛도 세진다
- 저항력 = Σ(기존 종교 비율 × 결속 계수) × (1 + 거부감) × 교리 보정
- 기존 종교 반격: 우리 비율이 오르면 그 나라 거부감이 자동으로 오른다.

### 실패 압력
- **정부 경계(alert)** 나라별 0~1. 신도 규모(가시성)·교리·유닛 활동·기적·선택지로 쌓이고 매달 조금 줄어든다.
  - 50%: 경고 (사건 카드 '경고장')
  - 70%: 압수수색. 본거지면 **계시 VIII**, 그 밖의 나라는 그 나라 유닛 몰수 + 신도 감소 (비밀주의는 피해 절반)
  - 100%: 그 나라 **활동 금지** (생산·유닛 행동 불가, 성장 크게 감소). 경계가 60% 아래로 내려가면 풀린다.
- **교단 결속(unity)** 0~100. 어두운 선택·분열 사건·후계 갈등으로 깎인다. 낮으면 이탈↑, 분열 사건 확률↑. 0이면 패배.
- **그림자 장부(riskPoints)**: 어두운 선택마다 쌓인다. 폭로·내부 고발·분열·세무 사건 확률을 올리고, 압수수색 대응 성공률을 낮춘다.
- **교주**: 창시 때 나이 30~55. 12턴마다 +1세, 70세부터 매달 사망 확률. 사망·체포 시 후계자가 있으면 계승(결속 손실), 없으면 패배.

### 신앙력 쓰임새
- 유닛 생산(보유 상한: 단계별), 기적(한 나라 1회 대형 전파, 재사용 대기·경계↑), 성지 건설(계시 VI 해금, 나라별 영구 보너스), 계시·사건 선택지 비용.
- HUD는 "다음 달 예상 수입", 턴 배너는 "이번 달 수입"으로 구분해 표기한다.

### 유닛
- 매달 이동 1회 + 활동 1회. 이동은 육로 이웃 또는 바다 건너 2칸.
- 유닛마다 '자동 임무' 토글: 켜면 턴 종료 때 제자리에서 알아서 활동한다.
- 행동하지 않은 유닛이 있으면 턴을 넘길 때 확인한다.
- 신학자는 육로 이웃이 없으면 해로 이웃에 절반 효과.

### 나라 기질과 현지 전도 방식 (`religion/culture.js`, 수치는 `CULTURE`·`APPROACH`)
- 나라마다 **기질**을 데이터로 판정한다: 대도시 · 농촌 · 무종교 많음 · 신앙 깊음 · 민간 신앙 · 다종교 · 통제 사회 · 자유 사회 · 섬나라 · 저소득 · 고소득.
  - 근거는 도시화·소득 등급·종교 자유도·종교 구성·육로 이웃 유무뿐이다. 민족·국민성 고정관념이나 특정 종교에 대한 평가는 쓰지 않는다.
- **유닛 궁합**: 같은 유닛도 기질에 따라 효과가 ×0.7~1.4로 달라진다 (예: 선교사는 통제 사회에서 약하고, 구호 활동가는 저소득 나라에서 강하다). 나라 패널과 생산 시트에 ▲▼로 표시.
- **현지 전도 방식**: 신도가 있는 나라마다 하나씩 고른다 (비용 15 × 단계 비용 배율).
  - 8종: 거리 전도 · 가정 소모임 · 온라인 방송 · 명상·인생 강좌 · 무료 급식·봉사 · 풍습 끌어안기 · 축제와 음악 · 공동체 마을.
  - 장점은 기질과의 궁합 점수에 따라 커진다 (잘 맞음 100% · 맞음 60% · 보통 30% · 안 맞음 −40% 역효과). 부수 효과(경계↑, 거부감↑, 유지비, 이탈↑ 등)는 궁합과 상관없이 따라온다.
  - 바꾸면 25%에서 시작해 4달에 걸쳐 자리를 잡는다. 기질상 가장 맞는 방식에 '추천' 표시.
  - 상태: `state.countries[id].approach = { id, since }`. 수정자 출처로 들어가 그 나라의 성장·유닛 전파·저항·이탈·경계에만 작용한다.

### 한국에서 바다 건너로
- 본거지는 늘 대한민국. 계시 II는 성소 장소만 고른다 (한국 안의 지역 유형 4곳).
- 시작 때 지구본은 한국에 바짝 붙어 있다. 처음으로 해외에 신도가 생기면 한 번 크게 줌아웃하며 세계가 보인다 (`flags.abroad`).
- 한국의 육로 이웃은 북한뿐이라 해외 경로를 따로 보장한다.
  - '바다 건너에서 온 초대장' 사건은 신도 1,000~5,000명 구간에서 반드시 한 번 나온다. 초대는 해외 한인 사회가 큰 나라에서 온다.
  - 해외 한인 비율이 높은 나라(`DIASPORA`: 일본·중국·미국·캐나다·호주·뉴질랜드·우즈베키스탄·카자흐스탄·러시아·베트남·필리핀 등)는 그 나라 신도가 적을 때 전파·증가 보너스.

### 무작위 사건 카드
- 3~5턴마다 1장 (계시 III 이후). 카드마다 등장 조건과 가중치(그림자 장부·결속·경계 반영).
- 사건마다 **형식**이 하나씩 있다: 단톡방 캡처 · 뉴스 속보 자막 · 문자 메시지 · 신문 1면 · 간부 회의 녹취록 · 탈퇴자 커뮤니티 글 · 공문.
- 선택지 수는 1~5개로 섞는다. 하나뿐인 강제 상황도 있다.
- 숨은 선택지(`visible(state)`)는 조건(특정 인물 생존, 특정 울타리, 그림자 장부 등)이 맞을 때만 보인다.
- 대놓고 나쁜 선택지(웃기지만 손해)도 가끔 넣는다.

### 성장 단계
- 컬트 → 신흥 종교(1만) → 국제 교단 → 세계 종교. 단계마다 유닛 전파 배율·신앙력 배율·유닛 보유 상한·유닛 해금이 오른다. 내려가지 않는다.

## 6. 계시 시스템 (`src/story/`)
- 계시 = `{ id, numeral, title, trigger(state), narration[], parts[], afterword? }`
  - part 종류: `choice`(선택지 카드, pickCount) · `text`(이름 입력). 나라 고르기는 없다 (한국 고정)
  - 선택지 = `{ id, label, flavor, say?[인물, 대사], effectText((i)에서만), odds?(성공 확률 → 3단계), dark?(그림자 장부 점수), cost?, available?(state) }`. label·flavor·say·narration 은 (state) → 값 함수여도 된다
  - 적용은 `apply(state, picks, rng)` 한 곳에서. 효과는 `state.extraModifiers`(수정자)와 `state.flags`로 남긴다. 확률 판정 결과는 `outcome` 문장으로 돌려준다.
- 각 계시는 조건을 만족한 턴이 끝날 때 **한 번만** 등장한다. I·II는 창시 직후, III은 지도가 열린 직후.
- 고른 선택은 `state.story.done[id]`에 남고, 메뉴의 **교단 연대기**에서 다시 볼 수 있다.

| 계시 | 제목 | 등장 조건 | 정하는 것 |
|---|---|---|---|
| I | 부름 | 창시 직후 | 절대 원칙(=신앙 대상) + 교단 이름 |
| II | 성소 | I 직후 | 성소 장소 (도심 상가 건물 · 강원도 산골 폐교 · 대학가 원룸촌 스터디 카페 · 서해 외딴 섬) |
| III | 첫 번째 씨앗 | 첫 턴 시작 | 포교 방식 (+선교사 민호) |
| IV | 울타리 | 신도 100명 | 울타리 3개 (=교리 슬롯 3개 해금) |
| V | 카메라 | 신도 1,000명 또는 본거지 거부감/경계 30% | 언론 위기 대응 |
| VI | 금고 | 신도 1만 명 | 자산 증식 방식 (+성지 건설 해금) |
| VII | 그림자 | 교주 60세 또는 창시 12년차 | 후계자(조카 서진 · 2인자 동철 · 꿈꾼 민호 · 불사 선언) + 납득 방식 |
| VIII | 사이렌 | 본거지 경계 70% | 압수수색 대응 (확률 판정) |
| IX | 봉쇄 | VIII 이후 3턴 | 봉쇄 돌파 방식 + 교주의 비망록 #1 |

### 계시 연출
- 암전(0.8초) → 위에서 빛줄기가 천천히 내려와 퍼짐 → 빛 속 먼지 입자(canvas)
- "계시 IV" 페이드인 → 제목 → 내레이션 한 줄씩 (클릭·탭하면 즉시 전부) → 질문과 선택지가 어둠 속에서 떠오름
- 선택지는 촛불에 비친 낡은 종이 쪽지. 본게임과 같은 종이 질감을 쓴다. 금빛 글로우 카드는 쓰지 않는다.
- "계시"에만 자간을 준다. 로마 숫자(I, II …)에는 자간을 주지 않는다 ("계 시 I I" 버그).
- 선택지마다 등장인물 한마디가 붙는다. 정확한 효과는 (i)를 눌렀을 때만.

## 7. 디자인: "싸구려 교단 인쇄물"
- 컨셉: 교회 주보, 동네 전단지, 복사기로 뽑은 안내문. 종이 질감, 약간 번진 인쇄, 도장, 형광펜, 테이프.
- 폰트: 제목은 명조(Nanum Myeongjo), 본문·강조는 고딕(Pretendard, 굵게). 손글씨(Nanum Pen Script)는 메모·대사에만.
- 색: 종이색 바탕 + 먹색 글자. 강조색은 교단 색 + 형광 노랑 + 인주 빨강. 시스템 파란색은 쓰지 않는다.
- 반투명 유리 카드, 알약 버튼, 큰 둥근 모서리를 쓰지 않는다. 패널마다 다른 지면을 쓴다:
  - HUD: 주보 머리 (호수·날짜·교단명), 나라 패널: 파일철 장부, 독: 메모지, 시트: 복사 안내문, 사건: 형식별 문서
- 타이틀: 전봇대에 붙은 반쯤 뜯긴 전단지 구도. 하단은 뜯어 가는 연락처 쪽지.
- 지구본: 종이 지도 색감. 우리 교단 영역은 형광펜으로 칠한 느낌.
- 라이트/다크는 시스템 설정을 따른다. 다크에서도 종이는 종이색(조금 어둡게), 바탕만 어둡다.
- 문양(`emblems.js`): 자연·천체·기하 모티프만. 기존 종교의 상징은 넣지 않는다.

### 숫자는 숨기고 말로 (`story/words.js`)
- 선택지 효과는 "▲ 이탈↓" 대신 등장인물 한마디. 정확한 효과는 (i) 버튼이나 길게 누르기로만.
- 성공 확률은 "자신 있음 / 반반 / 도박" 3단계.
- 결속은 "간부들 분위기" 5단계 문장. 정부 경계·거부감도 단계 문장.
- 정확한 수치는 메뉴의 **교단 장부** 화면에서만 본다. 신도 수와 신앙력(쓰는 자원)은 숫자 그대로.
- 시스템 문구(미행동 경고, 신앙력 부족, 생산 불가, 단계 상승, 승패)는 등장인물 대사로. 버튼도 업무용 앱 말투("확인", "취소", "다음") 대신 상황 말투.

## 10. 문장 규칙 (모든 문구에 적용)
금지:
- 끝에 반전 한 줄 붙이기 ("적어도 ~는.", "이번에는.", "너무 ~하게.") → 게임 전체 5번 이하
- "A일 수도, B일 수도", "X가 아니라 Y", "A지만 B" 대구 공식
- 세상·역사·운명·빛·어둠·영혼 같은 추상어 남발 (한 화면 1번까지)
- 줄표(—), 「」, ↑↓ 화살표 남발. ▲▼는 숫자 표에서만
- 모든 문장을 엄숙하게 쓰기

대신:
- 구체 명사: 동네 유형, 가게, 물건, 음식, 날씨, 시간, 금액
- 서술보다 대사(큰따옴표). 캐릭터마다 말투가 달라야 한다
- 블랙코미디: 교주는 진지한데 상황은 짠하고 웃기게
- 문장 길이를 섞는다. 짧은 문장만 연속 금지

예 (톤 참고용):
- 전: "세상은 틀렸고, 사람들은 길을 잃었다."
- 후: "새벽 4시, 편의점 야간 알바 끝나고 라면 물 올리는데 누가 분명히 내 이름을 불렀다. 집에는 나뿐이었다."
- 전: "아무 일도 없었다. 적어도 장부 위에서는."
- 후: "태식이는 다음 주에도 회계를 봤다. 새 차를 타고 왔다."

검사: `npm run lint:words` (tools/check-words.mjs)가 금지 패턴 개수를 센다. `src/`의 문자열만 본다 (주석 제외). 사건 문서 속 공문·커뮤니티 글처럼 일부러 딱딱하게 쓴 '극중 문서'는 존댓말·공문체를 써도 된다.
