# CLAUDE.md — 사이비 교주 블랙코미디 전략 게임 (이름 미정)

> 게임 이름은 아직 정하지 않았다. 정해지면 `src/config.js`의 `GAME.title`과 `index.html`의 `<title>`만 바꾼다.

이 문서는 게임의 설계 기준이다. 설계가 바뀌면 코드보다 이 문서를 먼저 고친다.

## 0. 원칙 (어기지 않는다)
- 풍자 대상은 **플레이어가 만든 가상의 교단**뿐이다. 실존 종교(기독교·이슬람교·힌두교·불교·유대교·민간 신앙·기타·무종교)는 배경 세력으로만 두고 비하하지 않는다. 모든 조직 종교는 같은 결속 계수를 쓰고, 효과는 나라 특성(도시화·소득·자유도)에만 반응한다.
- 실존 사이비 단체·교주의 이름, 사건, 교리를 연상시키는 고유명사는 쓰지 않는다.
- 어두운 선택에는 반드시 나중에 돌아오는 대가가 있다. "나쁜 짓 = 공짜 이득"이 되면 안 된다 (→ 그림자 장부).
- 선택지 문구는 게임적 묘사 수준으로만 쓴다. 현실에서 따라 할 수 있는 구체적 수법·절차는 쓰지 않는다.

## 1. 개요
- 평범한 사람이 어느 날 교주가 되기로 결심하고, 가상의 교단을 세계로 키우는 블랙코미디 턴제 전략 게임.
- 초반은 **계시**(스토리 장면)로 진행된다. 계시는 한 번에 몰아서 나오지 않고, 조건을 채운 턴이 끝날 때 하나씩 등장한다.
- 이후 세계지도(3D 지구본) 턴제 시스템이 본편이다. 1턴 = 1개월.
- 승리: 세계 인구의 30%가 신도.
- 패배: 신도 0 / 교주 체포(후계자 없음) / 교주 사망(후계자 없음, 또는 불사 선언 후 사망) / 교단 분열(결속 0).

## 2. 기술·배포
- Vite + 바닐라 JS (ES 모듈), 지도는 d3-geo(정사영 지구본)/d3-zoom + world-atlas `countries-110m`
- 국기: flag-icons(MIT) SVG를 `npm run flags`로 `public/flags/{iso2}.svg`에 복사해 함께 배포 (북키프로스·소말릴란드는 없음)
- 저장: localStorage `faith-game-save` (매 행동·매 턴 자동 저장, `saveVersion` + 마이그레이션 표)
- 레포 루트가 GitHub Pages로 서비스된다. 소스는 `faith-game/`, 빌드 결과는 **레포 루트 `faith/`** (`base: './'`). 배포물은 손으로 고치지 않고 `npm run build`로 다시 만든다.

```bash
cd faith-game
npm install
npm run dev        # 개발 서버
npm run build      # ../faith/ 로 빌드
npm run adjacency  # 국가 연결(육로·해로) 다시 계산
npm run flags      # countries.json에 iso2를 채우고 국기 SVG 복사
npm run sim        # 밸런스 표 (여러 플레이 성향 × 원칙·울타리 조합 × 시드)
node tools/simulate.mjs --home 410 --policy good --seed 3 --log   # 한 판 자세히
```

- `game/`, `religion/`, `units/`, `story/`(UI 파일 제외), `data/`는 DOM을 모른다 → 노드 시뮬레이터가 그대로 돌린다.

## 4. 데이터
- `countries.json`: `{ name, iso2, region, pop, urban, freedom(0~100), gdpTier(1~4), religions? }`. `religions`가 없으면 `regionDefaults[region]`(지역 평균).
- 키는 world-atlas 도형 ID(ISO 숫자). 코드 없는 도형은 `ids.js` (북키프로스 1001, 소말릴란드 1002, 코소보 383).
- `adjacency.json`: `land` 국경 공유, `sea` 해안선 650km 이내 + 수동 항로. 스크립트로만 고친다.

## 5. 핵심 규칙
### 성장
- 시작 신도 **3명**. 자연 증가율은 낮다(월 5~8% × (1−저항력) × 자유도) → 성장은 플레이어 행동(유닛·기적·성지)이 이끈다.
- 이탈 = 기본율 × (1 + 저항력 × 가중치) × 교리 × 결속 보정 × (1 − 수호자). 한 나라 신도가 1명 미만이면 0.
- 유닛 전파량 = 유닛 기본값 × 교리 보정 × (1 − 저항력) × 자유도 × **도달력** × 단계 배율
  - 도달력 = min((개종 가능 인구)^0.6, k × (전 세계 신도 + 씨앗)^지수) → 조직이 커질수록 유닛도 세진다
- 저항력 = Σ(기존 종교 비율 × 결속 계수) × (1 + 거부감) × 교리 보정
- 기존 종교 반격: 우리 비율이 오르면 그 나라 거부감이 자동으로 오른다.

### 실패 압력
- **정부 경계(alert)** 나라별 0~1. 신도 규모(가시성)·교리·유닛 활동·기적·선택지로 쌓이고 매달 조금 줄어든다.
  - 50%: 경고 (사건 카드 '경고장')
  - 70%: 압수수색. 본거지면 **계시 VIII**, 그 밖의 나라는 그 나라 유닛 몰수 + 신도 감소 (비밀주의는 피해 절반)
  - 100%: 그 나라 **활동 금지** (생산·유닛 행동 불가, 성장 크게 감소). 경계가 60% 아래로 내려가면 풀린다.
- **교단 결속(unity)** 0~100. 어두운 선택·분열 사건·후계 갈등으로 깎인다. 낮으면 이탈↑, 분열 사건 확률↑. 0이면 패배.
- **그림자 장부(riskPoints)**: 어두운 선택마다 쌓인다. 폭로·내부 고발·분열·세무 사건 확률을 올리고, 압수수색 대응 성공률을 낮춘다.
- **교주**: 창시 때 나이 30~55. 12턴마다 +1세, 70세부터 매달 사망 확률. 사망·체포 시 후계자가 있으면 계승(결속 손실), 없으면 패배.

### 신앙력 쓰임새
- 유닛 생산(보유 상한: 단계별), 기적(한 나라 1회 대형 전파, 재사용 대기·경계↑), 성지 건설(계시 VI 해금, 나라별 영구 보너스), 계시·사건 선택지 비용.
- HUD는 "다음 달 예상 수입", 턴 배너는 "이번 달 수입"으로 구분해 표기한다.

### 유닛
- 매달 이동 1회 + 활동 1회. 이동은 육로 이웃 또는 바다 건너 2칸.
- 유닛마다 '자동 임무' 토글: 켜면 턴 종료 때 제자리에서 알아서 활동한다.
- 행동하지 않은 유닛이 있으면 턴을 넘길 때 확인한다.
- 신학자는 육로 이웃이 없으면 해로 이웃에 절반 효과.

### 무작위 사건 카드
- 3~5턴마다 1장 (계시 III 이후). 최소 12종. 카드마다 등장 조건과 가중치(그림자 장부·결속·경계 반영), 선택지 2~3개.

### 성장 단계
- 컬트 → 신흥 종교(1만) → 국제 교단 → 세계 종교. 단계마다 유닛 전파 배율·신앙력 배율·유닛 보유 상한·유닛 해금이 오른다. 내려가지 않는다.

## 6. 계시 시스템 (`src/story/`)
- 계시 = `{ id, numeral, title, trigger(state), narration[], parts[], afterword? }`
  - part 종류: `choice`(선택지 카드, pickCount) · `text`(이름 입력) · `country`(나라 고르기)
  - 선택지 = `{ id, label, flavor, effectText, dark?(그림자 장부 점수), cost?, available?(state) }`
  - 적용은 `apply(state, picks, rng)` 한 곳에서. 효과는 `state.extraModifiers`(수정자)와 `state.flags`로 남긴다. 확률 판정 결과는 `outcome` 문장으로 돌려준다.
- 각 계시는 조건을 만족한 턴이 끝날 때 **한 번만** 등장한다. I·II는 창시 직후, III은 지도가 열린 직후.
- 고른 선택은 `state.story.done[id]`에 남고, 메뉴의 **교단 연대기**에서 다시 볼 수 있다.

| 계시 | 제목 | 등장 조건 | 정하는 것 |
|---|---|---|---|
| I | 부름 | 창시 직후 | 절대 원칙(=신앙 대상) + 교단 이름 |
| II | 성소 | I 직후 | 본거지 나라 + 성소 유형 |
| III | 첫 번째 씨앗 | 첫 턴 시작 | 포교 방식 (+선교사 1명) |
| IV | 울타리 | 신도 100명 | 울타리 3개 (=교리 슬롯 3개 해금) |
| V | 카메라 | 신도 1,000명 또는 본거지 거부감/경계 30% | 언론 위기 대응 |
| VI | 금고 | 신도 1만 명 | 자산 증식 방식 (+성지 건설 해금) |
| VII | 그림자 | 교주 60세 또는 창시 12년차 | 후계자 + 납득 방식 |
| VIII | 사이렌 | 본거지 경계 70% | 압수수색 대응 (확률 판정) |
| IX | 봉쇄 | VIII 이후 3턴 | 봉쇄 돌파 방식 + 교주의 비망록 #1 |

### 계시 연출
- 암전(0.8초) → 위에서 빛줄기가 천천히 내려와 퍼짐(블러 그라데이션, 미세한 일렁임) → 빛 속 먼지 입자(canvas)
- "계시 IV" 넓은 자간 페이드인 → 제목 → 내레이션 한 줄씩 (클릭·탭하면 즉시 전부) → 질문과 선택지 카드가 어둠 속에서 떠오름
- 선택하면 고른 카드만 빛나고 나머지는 사라진 뒤 지도로 복귀. 세리프 폰트. `prefers-reduced-motion`이면 모션 최소화. 모바일에서 선택지가 잘리지 않게 스크롤.

## 7. 디자인
- **패널 UI**(HUD·나라 패널·독·시트): iOS 기본 앱 톤. 무채색 바탕 + 반투명 카드, 강조색은 종교 색 하나. 장식 금지.
- **지도·연출**(지구본, 계시, 전파 파동, 새 나라 진입, 단계 상승): 장식 금지 규칙을 적용하지 않는다. 분위기 있게.
- 라이트/다크는 시스템 설정을 따른다. 모든 UI 문구는 한국어.
- 지도는 3D 지구본. 나라를 고르면 대권을 따라 돌면서 '패널·독을 피한 보이는 영역'의 가운데로 날아간다.
- 문양(`emblems.js`): 자연·천체·기하 모티프만. 기존 종교의 상징은 넣지 않는다.

## 8. 저장 형식
- v1 → v2: `religion.emblem` 추가
- v2 → v3: 계시 시스템. `story`, `leader`, `unity`, `riskPoints`, `holySites`, `rng`, 유닛 `auto` 추가. 이전 저장은 계시 I~IV를 이미 지난 것으로 보고 이어간다.

## 9. 밸런스 목표 (`npm run sim`으로 확인)
- 방치 플레이(턴만 넘김)는 어떤 조합으로도 승리 불가
- 신도 100명(계시 IV) 6~10턴, 1,000명(계시 V) 15~25턴, 1만 명(계시 VI) 30~45턴
- 괜찮은 플레이로 승리까지 180~300턴, 원칙·울타리 조합 간 승리 턴 차이 1.5배 이내
- 어두운 선택만 고른 플레이는 초반은 빠르지만 후반 분열·체포 확률이 확실히 높다

### 현재 결과 (시드 3개 중앙값, 턴 = 개월)

|---|---|---|---|---|
| 방치 (원칙 5종 × 3개국) | — | — | — | 21판 모두 패배 (신도 0 · 분열, 75~137턴) |
