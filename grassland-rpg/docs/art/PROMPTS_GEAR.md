# 새 장비 132종 그림 요청 (ChatGPT)

지난번 아이템 그림을 받던 방식과 같습니다. **14묶음**(8~10개씩)이고, 묶음마다 그림 2장만 첨부하면 됩니다.

## 쓰는 법

1. **새 대화**를 열고 아래 「처음 한 번」 글 + `docs/art/style_anchor.webp` 를 보냅니다. (지난번에 쓰던 대화를 이어서 써도 됩니다)
2. 묶음마다 **첨부 2장**을 올립니다.
   - `gear/batch_NN.png` — 번호가 붙은 지금의 임시 아이콘 (모양·색의 출발점)
   - `gear/style_<부위>.png` — 이미 있는 같은 부위 그림들 (그림체를 맞추는 기준)
3. 회색 상자 글을 통째로 붙여 넣어 보냅니다.
4. 받은 그림을 이 대화에 **"장비 묶음 N"** 이라고 적어서 올려 주세요. 나누기·이름 붙이기·배경 지우기·게임에 넣기는 제가 합니다.
5. 몇 묶음마다 그림체가 흐려지면 새 대화를 열고 1번부터 다시.

**문제가 생기면 바로 쓸 문장**
- 붙거나 겹침 → `Redraw with more empty transparent space between the objects — no object may touch or overlap another.`
- 개수·순서가 틀림 → `There must be exactly the listed number of objects, in the listed order: left to right, top row first. Please redraw.`
- 그림체가 다름 → `Match the second attached image (existing items) much more closely: same outline thickness, same shading, same cute chunky proportions.`

## 처음 한 번 (새 대화일 때)

```
I'm making item icons for my cozy low-poly fantasy game. The attached image is the approved style anchor.
Every icon you draw must match it: dark warm-brown outline (#3b2d22), light from the top-left, soft cel shading,
cute and chunky shapes, white highlights, readable at 48×48 px, transparent background, no text.
I will send batches of items. Each batch comes with (1) the current numbered placeholder icons and
(2) existing finished icons of the same kind — new icons must look like they belong to the same set as (2).
Reply "ready" and wait for the first batch.
```
